# platinumlinedsolutions.com

The public site of Platinum Lined Solutions LLC — static HTML/CSS, no build step, no frameworks.

- Design system: `styles.css` ("Assay Office" — chalk/ink drafting rules, platinum hallmark stamps, PLS champagne-gold accent; dark mode uses the product's own navy-slate palette).
- Type: Cabinet Grotesk + Switzer, self-hosted in `fonts/` (fetched once via `fetch-fonts.js` from Fontshare — no CDN calls, no tracking).
- Hosted on GitHub Pages; `CNAME` pins the custom domain.

To update: edit the HTML, push to `main`. Pages redeploys automatically.
